Background

A key NSFC-supported project on access control for heterogeneous data.

Public challenge

Expressing and enforcing multi-factor access-control policies consistently across heterogeneous big-data platforms.

My role

  • Implementation of multi-factor policy management and access control
  • Integration with Hadoop and Huawei FusionInsight HD

Project notes

How I approached it

The project built unified authorization around attribute types, operation matching, and platform integration, followed by integration and application demonstrations on heterogeneous big-data platforms.

Public outcomes

  • Supported 7 attribute data types and 142 attribute-operation matching functions
  • Integrated with Hadoop and Huawei FusionInsight HD
  • Passed third-party stability and reliability testing
